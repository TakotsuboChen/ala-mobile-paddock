消息配置

被动回复：群消息满足条件时 bot 以引用该消息的形式回复模板。主动播报：满足条件的事件发生时 bot 向勾选的群推送消息（未认证应用主动消息额度极低，可能被平台限流）。多个条件可用「满足全部 / 满足任一」组合；内置动作（注册校验/密码重置）的触发词是提取锚点，码/用户名取其后的内容。
