站点品牌

Telegram 机器人

webhook 回调地址：https://<域名>/tg/webhook（保存 token 时自动调用 setWebhook 注册，结果显示在提示里）。

⚠️ 隐私模式：Telegram bot 默认收不到群内全部消息。需在 BotFather /setprivacy 关闭后把机器人移出群再重新拉进来（对已存在的群不立即生效），或直接把机器人设为群管理员（立即生效）。

Telegram 播报目标群

Telegram 没有「查询我加入了哪些群」的接口，只能靠 bot 收到消息被动登记。若列表为空，请把群 chat_id（形如 -1001234567890）手动填入下方输入框添加。

QQ 机器人

webhook 回调地址：https://<域名>/qq/webhook（开放平台「回调配置」填此地址，勾选 GROUP_MESSAGE_CREATE；IP 白名单填服务器公网地址）

播报目标群

bot 收到过消息的群会自动出现在下面，勾选即播报；多群时消息模板不能使用 QQ 群用户名 变量。

消息配置

被动回复：群消息满足条件时 bot 以引用该消息的形式回复模板。主动播报：满足条件的事件发生时 bot 向勾选的群推送消息（未认证应用主动消息额度极低，可能被平台限流）。多个条件可用「满足全部 / 满足任一」组合。内置动作的触发语义随动作选择动态显示（如注册校验=消息含触发词且其后有 #校验码，提不出码静默不响应；密码重置/查询用户名=消息严格等于触发词，账号按发言者群身份自动匹配）。

管理员账号

修改后需用新用户名重新登录。

对象存储（阿里云 OSS）

配置后头像改为「客户端直连对象存储」：模块拿到 OSS 绝对 URL，图片字节不再经过本服务器。 所有字段均为必填，AccessKey Secret 保存后不再回显。未配置时系统继续用内置 Garage，行为不变。

填公网域名任何情况都能用。填内网域名（-internal 后缀）只有 bucket 与 ECS 同地域时才能连上——跨地域时内网域名无法解析。不确定就填公网域名。

只能含小写字母、数字和连字符（会进域名）。

形如 cn-hangzhou，必须与 bucket 实际所在地域一致——填错会签名失败（403），不是「区域不支持」。

必须含 https://，且是公网域名（内网域名客户端连不上）。 留空则按 https://{bucket}.{endpoint} 自动推导——只有服务端也走公网时才正确。

存量头像迁移

把现有头像搬到对象存储并压缩到 256×256。可重复执行（已迁移的会自动跳过）， 原图备份到 avatars_orig/，保留 30 天可回滚。 迁移不会改动用户的换头像冷却，也不会让客户端重新下载头像。
